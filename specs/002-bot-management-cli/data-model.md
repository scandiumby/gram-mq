# Data Model: Управление ботами через CLI (MVP: bot add)

**Date**: 2026-10-11 | **Spec**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md)

## Сущности

### Bot (реестр) — существует с фичи 001, не меняется

| Поле | Тип | Ограничения |
|---|---|---|
| bot_slug | String, PK | slug-safe ASCII, формат см. «bot_slug» ниже |
| created_at | timestamptz NOT NULL | server_default now() |

Изменений схемы нет — новых миграций фича не создаёт. CLI добавляет только
санкционированный путь появления строк (FR-001).

### Файл конфигурации бота `bots/.env-<bot_slug>` — новый артефакт

| Ключ | Формат | Ограничения |
|---|---|---|
| GRAMMQ_BOT_TOKEN | `{id}:{secret}` | ровно один `:`; id — непустое число; secret — непустой; без внешних пробелов и встроенных переводов строки |
| GRAMMQ_BOT_NAME | текст | одна строка, непустая, без управляющих символов; допустим `=` (парсинг по первому `=`) |

Файл: режим 0600, владелец — выделенный пользователь сервисов; каталог
`bots/` — 0700. Формат читается штатно как env-file (pydantic-settings),
записывается CLI (research R6).

## Контракт значения bot_slug

```
slug      := digits "-" word "-" word
digits    := последние 4 цифры числового id токена, zero-pad слева ("42" → "0042")
word      := слово из встроенного Dune-вордлиста (ASCII lower, буквы и дефисы, ≤ 12 символов), слова пары различны
```

- Итог ≤ 30 символов, regex `^[0-9]{4}(-[a-z-]+){2}$` (слова могут
  содержать дефис — например `shai-hulud`).
- Уникальность: среди PK реестра И имён существующих путей
  `bots/.env-<slug>`; коллизия → перегенерация (≤ 50 попыток).
- Публичная утечка — только 4 цифры id (принято спекой, Assumptions).

## Валидация токена (единый контракт формата)

```
token := numeric_id ":" secret
numeric_id := [0-9]+ (непустое число)
secret     := непустая строка без ":" и без управляющих символов/переводов строки
```

Внешние пробелы/переводы строки обрезаются до проверки; встроенный
перевод строки — ошибка формата. Один и тот же валидатор используется:
при вводе визарда (FR-005) и при чтении файлов в сверке дублей/готовности
(FR-012, Future US2).

## Валидация имени бота

Одна строка, после обрезки внешних пробелов непустая, без управляющих
символов и переводов строки (не ломает dotenv-разбор файла);
предельная длина — 64 символа (защита от инфляции файла; план R5/R6).

## Переходы состояний

Отдельной машины состояний нет. Жизненный цикл регистрации один переход:

```
(нет бота) ──bot add OK──► файл bots/.env-<slug> (0600) + строка реестра
(нет бота) ──сбой/отмена──► (нет бота)   # компенсация: unlink файла, откат сессии
```

Готовность к доставке — не хранимое состояние, а вычислимый признак:
файл существует И токен в нём форматно валиден (используется фичой 003 и
Future US2).
