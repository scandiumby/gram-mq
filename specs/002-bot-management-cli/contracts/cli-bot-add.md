# Contract: gram-mq bot add

**Date**: 2026-10-11 | **Spec**: [spec.md](spec.md) | Публичный интерфейс фичи (CLI).

## Сигнатура

```
gram-mq bot add          # подкоманда без флагов; весь ввод — интерактивный
python -m gram_mq bot add   # эквивалент
```

Неинтерактивный режим (флаги, stdin-пайпы значений) отсутствует by design
(spec, Assumptions). Токен никогда не передаётся аргументом или переменной
окружения (FR-004).

## Поток визарда

```
1. Проверки до начала ввода (любая ошибка → exit 2, ничего не создано):
   - настройки читаются (GRAMMQ_DATABASE_URL обязателен; fail-fast)
   - bots/ существует? → владелец == текущий пользователь И это каталог
   - bots/ не существует? → будет создан (0700)

2. Имя бота:
   prompt: "Имя бота: "
   пусто/пробелы/управляющие символы → повтор prompt (сообщение об ошибке)

3. Токен (скрытый ввод, getpass):
   prompt: "Токен бота ({id}:{secret}): "
   невалидный формат → сообщение БЕЗ токена + повтор prompt

4. Сверка дублей: id токена против всех bots/.env-* (research R8)
   дубль → exit 3, понятная ошибка, артефактов нет

5. Создание артефактов (research R7):
   файл bots/.env-<bot_slug> (O_EXCL, 0600) → строка реестра (INSERT)
   неудача вставки → unlink файла, откат, exit 4

6. Итог (FR-010):
   "Бот зарегистрирован"
   "  имя:  <имя>"
   "  slug: <bot_slug>"
   "  файл: <абсолютный путь bots/.env-<bot_slug>>"
   # токен не выводится
```

## Коды возврата

| Код | Смысл |
|---|---|
| 0 | бот зарегистрирован |
| 2 | окружение/предусловия (настройки, владелец bots/, лимит перегенераций slug) |
| 3 | дубль токена (FR-012) |
| 4 | сбой записи (реестр/файл) после компенсации — система в исходном состоянии |
| 130 | отмена оператором (Ctrl+C или Ctrl+D/EOF) на любом шаге — артефактов нет (FR-009) |

## Инварианты интерфейса (проверяются тестами и quickstart)

- Секретная часть токена не появляется: в prompt'ах, ошибках валидации,
  итоговом выводе, трейсбеках (FR-008; SC-002).
- `bot list` (US2, Future) в CLI-скрипте пока отсутствует: обращение к
  `gram-mq bot list` → exit 2 с сообщением «команда появится после US2
  (post-MVP)» — точка расширения зафиксирована, а не молчит.
- Файл токена и каталог: 0600 / 0700, владелец — пользователь сервисов
  (FR-014).
- Никакого HTTP-интерфейса регистрации не появляется (FR-002, SC-004).
